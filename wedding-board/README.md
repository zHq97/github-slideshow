# 通州梨园婚宴决策看板（Cloudflare Pages）

本目录由 Cursor 维护，推送到 `master`/`main` 后经 GitHub Actions **自动发布**到 Cloudflare Pages。

- 本地预览：浏览器直接打开 `index.html`（需联网）
- 生产项目名：`wedding-liyuan-board`
- 预期地址：`https://wedding-liyuan-board.pages.dev`（以 Cloudflare 控制台为准）

## 一次配置（只需做一次）

见仓库根目录 `wedding-board/README-AUTO-DEPLOY.md` 或 Obsidian `08`/`09` 文档。

需要 GitHub Secrets：

- `CLOUDFLARE_API_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`

**不要**把邮箱密码交给任何人；只用 API Token。
